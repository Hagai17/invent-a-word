An entry for the make.fun bounty [Invent a Word We Need](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0):
coin one new English word and define it in a single clear line of at most 140 characters.

## The entry

> **routelie** (n.): the "on my way" text sent from the sofa by someone who has not yet stood up.

English has no word for the departure you announce long before you make it — the text
everyone has sent and everyone has received. *Routelie* (route + lie) names it: sayable,
spellable, and recognisable in one reading.

## How it runs

`main.py` (program/v1, Python 3, no dependencies) writes the entry to
`/output/entry.txt` and prints it. It first checks the text against the gate
(1–140 characters, not only white space, one line) and verifies the written file
round-trips byte for byte, so the output is deterministic on every run.

## Process

`candidates.md` records the field scan (2,702 finished entries listed, 354 artifact
texts sampled and read), the 12 drafts, the head-to-head duels run under the judge's
published criteria in both orders, and the iteration from the first version of the
winning line to the final one.
